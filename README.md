# **Code Runner – Run Your Code, Anytime, Anywhere!** 🚀

### **Embedded Preview**  
![Project Preview](https://drive.google.com/uc?id=1ac0Jbip8hDQ1vI6kKUHza1m2S-MvSakE)

This is a **web-based code compiler** that supports **Java** and **Python**. It allows users to write, run, and test their code in a browser. Built with **Node.js, Express, and CodeMirror**, it provides an interactive coding environment.

## **Features** ✨

✅ **Supports Java & Python** – Select your language and start coding  
✅ **CodeMirror Integration** – Syntax highlighting and auto-closing brackets  
✅ **Run Code Instantly** – Executes code with input support  
✅ **Responsive UI** – Built with Bootstrap for an optimal user experience  

## **Tech Stack** 🛠️

- **Frontend:** HTML, CSS, Bootstrap, CodeMirror  
- **Backend:** Node.js, Express.js, Compilex  
- **Execution:** Runs code using a local compiler
